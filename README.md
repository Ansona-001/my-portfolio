# 🌐 Personal Portfolio

Welcome to my personal portfolio website!  
This portfolio showcases my skills, projects, and experience as a software developer, built with a modern and performance-focused tech stack.

🔗 **Live Website:**  
👉 https://portfolio.ansonaa.com

---

## ✨ Features

- Responsive design (mobile & desktop friendly)
- Smooth animations using **Framer Motion**
- Clean and modern UI with **Tailwind CSS**
- Fast build and optimized performance using **Vite**
- Type-safe codebase with **TypeScript**

---

## 🛠 Tech Stack

- **Frontend:** React 18, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Build Tool:** Vite

---

## 📦 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Ansona-001/my-portfolio.git
```

Navigate to the project folder:
cd portfolio

Install dependencies:
npm install

Run the development server:
npm run dev

Open your browser and visit:
http://localhost:5173
